## 🚀 How to Run Locally

1. Clone or download the repository:
   ```bash
   git clone https://github.com/priyankapanwar0302/bdayy.git
   cd bdayy
   ```
2. Double-click `index.html` to open directly in any web browser, or launch with Python:
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000`.
